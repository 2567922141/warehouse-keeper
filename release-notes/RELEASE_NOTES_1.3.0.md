# Warehouse Keeper 1.3.0（Minecraft 26.3）

> 内置 Carpet 与语音包，补齐 issue #7 / #8 的修复，并重做区域显示与取色盘。

- 游戏版本：Minecraft 26.3（Fabric Loader 0.19.5）
- 主体版本：1.3.0；内置语音：0.5.0
- 安装包：`warehouse-keeper-1.3.0.jar`

## 新增

- **内置 Carpet**：以 Jar-in-Jar 打包 Carpet 26.3（MIT），搬运工开箱即用，不需要另外放 Carpet。
  若 `mods` 里仍然装着 Carpet，加载器按 root 优先只保留一份，不会冲突。
  许可与来源见仓库内 `THIRD-PARTY-NOTICES.md`。
- **内置语音取货（默认关闭）**：主体包内置 `warehouse-keeper-voice` 0.5.0，不需要另放 jar。
  新安装默认关闭，到 设置 → 语音取货 打开「启用语音取货」后生效（等价于 `settings.txt` 的 `enabled=on`）。
  识别模型仍按需下载（SenseVoice 默认约 228 MB，另有 Paraformer 小 / Zipformer-CTC / Paraformer 完整版，可从官方、魔搭、hf-mirror 或自动选源，支持断点续传与 sha256 校验）。
  旧的独立语音包设置文件没有 `enabled` 行时按开启迁移，原有模型、别名与 AI 配置继续有效。
- **仓库代表色**：`/warehouse region color <仓库> [颜色]`；维护页提供调色盘（色轮 + 明度条 + 六条 H/S/V/R/G/B 滑条 + 预设 + 历史），默认白色。
- **区域显示改为半透明长方体**：按代表色绘制并标注仓库名，只画同维度 128 格内的仓库；框体高度跟随仓库里实际的箱子（最低箱子往下 8 格、最高箱子往上 8 格）。
- **暂存箱入仓**：不在任何仓库范围内、且开启「暂存」的箱子，标签栏多出「仓库」下拉与「整理入仓」按钮；由值守该仓库的搬运工搬进仓库。
  这类箱子不计入统计、也不参与整理。
- **仓库改名**：`/warehouse region rename <旧名> <新名>` 与维护页改名输入框；搬运工正在整理该仓库时拒绝。
- **权限成员管理**：`/warehouse user add|remove <玩家名>`，`user perm` 对未登记玩家会自动建行；面板「权限」页新增玩家名输入框与「添加」按钮。

## 变更

- 取货库存判定：下单按「有假人值守的仓库合计」判断，派单按各假人值守仓库的实际可供应量从多到少选人；选中仓库不够时先等有货的搬运工，而不是直接失败。
- 语音侧库存预检：快照数量不足时照常下单，只在回显里提示「服务端将复核库存」。
- 玩家可见文案统一为书面语，去掉语气词与口语动词。
- 「完全调用 AI 改写」改为只走 AI：本地匹配与复判都不参与，超时 / 未配置 / 回答不合法时只提示。
- 设置页控件改为固定行高 + 滚轮翻页，窗口再小按钮也不缩水。
- 版本号：主体 1.3.0、语音 0.5.0。

## 修复

- 物品页分类下拉只有「全部分类」（物品页补发 `KIND_OVERVIEW` 查询）。
- 附加属性显示组件 ID 与 SNBT（`Variants.friendly` 兜底改为可读值）。
- 管理员提示「没有权限记录」且命令不可用（`user perm` 自动建行）。
- 取货框显示 `id@hash`（带组件变体的行改为填服务端整行名）。
- 取色盘元素重叠、色轮有台阶感（改为 256×256 烘焙贴图）。
- 容器标签栏的仓库下拉展开位置错误。
- 仓库颜色改动后不刷新（区域签名纳入颜色）。
- 整理入仓 0 秒收工（先让搬运工走近暂存箱、等区块加载；失败时给出具体原因）。

## 移除

- 地图联动（JourneyMap）整块删除。
- `SWEEP` 清扫任务的残留入口。

## 安装

1. 删除旧版 `warehouse-keeper-*.jar` 与旧版独立语音包（若还在 `mods` 里）。
2. 把 `warehouse-keeper-1.3.0.jar` 放进 `mods` 目录。
3. 启动游戏，进入存档；面板快捷键不变。
4. 需要语音时到 设置 → 语音取货 打开开关。
