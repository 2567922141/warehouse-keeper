# Warehouse Keeper v1.1.3

Issue #4 修复版。这一版针对 2026/10/6 的实机反馈（GitHub issue #4「1.多人游戏下，客户端取货界面里的分类列表有时没有分类，只剩下『全部分类』和『其他』两类。2.因为假人算一个玩家，导致假人过多后显示服务器已满，其他真实玩家无法加入游戏。」）修掉分类下拉退化成两项的问题，并让搬运工不再占用服务器的玩家名额。

## 🐛 问题修复

- **多人游戏下，客户端取货页的分类下拉只剩「全部分类」和「其他」**：取货页的分类以前是**客户端现算**的 —— 它依赖一张「物品 → 创造模式页签」的对照表，而那张表只有服务端建得起来（服务端启动时会用创造模式页签重建一次内容）。于是访客（连专用服的玩家、局域网里的客人）进程里没有服务端，每件物品都被算成「其他」，下拉自然只剩那两项；单机与房主因为服务端就在同一个进程里，一直是正常的 —— 这就是报告里写「有时」的来源。
  现在服务端在建索引时就把类目键算好，随仓库快照**逐行下发**给客户端（字段 `category`），面板优先用它；分类候选的顺序也改成「服务端下发的类目清单 → 本机页签注册表 → 旧版清单」三级回落。老服务端不发这个字段时，客户端仍然按原逻辑现算，行为与 1.1.2 完全一致。
  顺带修掉两个会让「按分类筛选」一件都筛不出来的坑：一是快照字段名与客户端字段名不一致（Gson 按字段名对拷，两边一字不差才有值），二是「全部仓库」范围下把多个仓库的同种物品合并成一行时漏拷了类目。

## ⚡ 优化

- **搬运工不再占用服务器的玩家名额**：搬运工是 Carpet `/player <名字> spawn` 出来的**真正的服务器玩家**，而原版的满员判定数的是「所有在线玩家」，于是名册里放几个搬运工就等于占了几个名额 —— 假人一多，真人进来只会看到「服务器已满」。
  现在新增一处很小的 Mixin，**只把本模组名册里的搬运工**从满员计数里剔掉。封禁、IP 封禁、白名单、重复登录与 OP 免限这几条检查一个都没动，`server.properties` 里的 `max-players` 也不用改；它写在通用段而不是仅服务端段，所以局域网联机的单机存档也一并生效。
  注入点带 `require = 0`：将来原版代码变动导致注入点对不上时，只会静默退回原版行为，不会崩服。处理函数对拿不到玩家档案的条目一律按真人计算，宁可少放一个搬运工，也不放宽真人限制。

## ⬆️ 升级提示

- **旧版本替换即可**：删除 `mods/` 里的旧 `warehouse-keeper-*.jar`，换成 `warehouse-keeper-1.1.3.jar`。注意不要在 `mods/` 里同时留下新旧两个 jar（同一模组 ID 会导致加载失败）。
- **联机时服务端要一起升到 1.1.3**：分类键是服务端随快照下发的；只升客户端会出现「分类名是真的、但选它一件都筛不出来」。反过来（服务端 1.1.3 + 旧客户端）没有问题，老客户端会忽略这个新字段。
- 「搬运工不占名额」只需**服务端**装 1.1.3；单机与局域网房主的客户端本身就带服务端。
- 配置、标签、权限、仓库定义、审计与索引都在 `config/warehouse-keeper/` 下，原样沿用；本版**没有**改索引格式，不需要重新扫描仓库。
- 升级后建议依次点一遍：进多人服务器 / 局域网联机后打开面板「取货」页，展开分类下拉，确认里面是真实类目（不再是「全部分类 / 其他」两项）；选一个分类，确认清单与「共 N 种物品」跟着变、表头出现「（分类：xxx）」；再确认 `max-players` 设得比假人数小时，真人依然能进服。

## ⚠️ 已知限制

- **未装模组的原版客户端**仍看到假人的 Carpet 注册名（显示名只通过本模组在客户端渲染时替换，服务端并没有改名）；玩家列表（Tab）、指令、任务、`/warehouse bot list` 也一律使用注册名 —— 注册名是身份，改了等于换人。
- **搬运工不占名额的判断只看本模组的名册**：别人用 `/player` 手工召出来的假人照样占名额（这是有意的，避免影响非本模组生成的假人）。
- 分类候选只看「取货范围」，不看筛选框里的字：因此可能出现「某分类 + 某关键字 = 0 种物品」（表头会显示 0，换个分类或清空筛选即可）。
- 「仓库 → 物品」子页的分类下拉候选来自服务端按需查询；服务端不支持按需查询（较旧版本服务端）时它只剩「全部分类」。
- 工作方块（工作台/熔炉/高炉/烟熏炉等带配方书的界面）打开时不再显示容器标签栏：原版会把界面右移，而 26.2 没有公开的几何访问口，模组只能按居中估算，算出的竖栏会压住物品栏；铁砧、切石机等不受配方书影响的界面照旧显示。
- 面板布局面向 720P 及以上分辨率设计，极窄窗口下部分区域会按可用空间降级或隐藏。
- 未安装 Carpet 时搬运工不可见，仅能通过指令与面板观察作业结果。
- 专用服务端在没有客户端连入时，指令输出中的物品名为英文。
