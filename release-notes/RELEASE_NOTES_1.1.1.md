# Warehouse Keeper v1.1.1

多人联机体验修复版。这一版针对 2026/10/4 的实机反馈，修掉「部分数据更新不及时」（标签栏类目、面板刷新），并让**一个仓库可以由多名搬运工同时整理**。

> 本版本**没有改动索引格式、配置文件与指令语法**：升级只需替换 jar，已有仓库定义、标签、权限、审计与索引都可直接沿用，不需要重新扫描。

## 🐛 问题修复（多人游戏数据更新不及时）

- **标签栏类目对不上（房主有、别人没有）**：类目清单原来只在服务端进程里生成，非房主（访客）进程拿不到创造模式页签表，下拉会退化成旧版类目名 —— 看起来就是「新版本标签同步不过来」。现在类目表随仓库快照一起下发，客户端再按「服务端下发的清单 → 本地顺序 → 本机页签注册表 → 旧版清单」四级回落，房主与所有客户端显示一致；房主新贴的类目也会同步到其他玩家。
- **空闲一段时间后的第一次变化要等约 1 秒**：空闲冷却原来会把推送时钟重置成慢档，现在改完立刻按快节奏推送。
- **假人收回/放出、整理进度变化不推送**：快照指纹补齐「假人在不在岗」与「整理进度档」两项，这些变化现在都会触发推送。
- **漏收的玩家要等下次变化才补上**：新增补发名单，未送达者在 60 秒内反复重试，不再长期停在旧数据上。
- **超大快照导致全服静默不更新**：标签数量新增上限（4000），超限不再拖垮整份快照；`/warehouse status` 现在会显示「组包大小 / 上限 / 待补发人数 / 过大跳过次数」，便于排查。
- **`/warehouse categories reload` 没刷新缓存**：现在会同时作废类目缓存、创造模式页签顺序与网页快照，改完覆盖表全服的分类统计立刻跟上。
- **管理员推中文物品名后，普通玩家游戏内不更新**：网页快照与游戏内快照现在都会跟着刷新（原来只刷新了网页）。
- **组包失败会「静默停更」**：改为组包成功后才记账；失败写日志并在下一轮重试，不会一直卡在旧数据上。

## ✨ 体验优化（一个仓库多个搬运工）

- **整仓派单给全部在场搬运工**：`/warehouse porter tidy <仓库>`（面板上的整理按钮同样）会把该仓库在场的**所有**搬运工编成一组，按箱子位置哈希把箱子分片给每人，各片互不重叠、数量天然均衡。
- **中途有人退出会自动重摊**：某名搬运工被收回、被停或出错时，剩下的同伴按实际人数重新分片，不会留下「整片箱子这一轮没人碰」。
- **进度看得见**：搬运工名册的「在忙什么」列显示「本片 a/b 箱 · 全仓 x/y 箱」，一眼能看出谁在管哪一片、整体还有多少。
- **派单不再「已经有人就挡回」**：`/warehouse porter staff <仓库>` 会继续补人，并提示该仓库现有几名搬运工。
- **换箱立即释放认领**：整理途中换目标箱子时立刻释放上一只的认领，同伴不用等前一人干完整轮。

## 🔧 顺手修掉的隐患

- **容器标签栏的木桶串标签**：「双联箱兜底」的判据收窄为「原版箱子 / 带箱子 TYPE 属性的模组箱子」，木桶、潜影盒、漏斗等永不成对的容器不再把邻居那格的标签显示到自己身上。
- **异常条目中断整轮任务**：整理顺序或类目注册表兜底里出现异常/空条目时跳过该条，不再让整轮整理莫名中止。

## ⬆️ 升级提示

- **旧版本替换即可**：删除 `mods/` 里的旧 `warehouse-keeper-*.jar`，换成 `warehouse-keeper-1.1.1.jar`。注意不要在 `mods/` 里同时留下新旧两个 jar（同一模组 ID 会导致加载失败）。
- 配置、标签、权限、仓库定义、审计与索引都在 `config/warehouse-keeper/` 下，原样沿用；本版**没有**改索引格式，不需要重新扫描仓库。
- 联机时**服务端与客户端都要装**本模组，且**版本需一致**（服务端 1.1.1 会向客户端下发类目清单，旧客户端也能玩，但拿不到类目同步与即时刷新）。
- 升级后建议在面板上依次点一遍：标签栏下拉是否与房主一致、收回/放出搬运工后面板是否 1 秒内刷新、同一仓库派两名搬运工的进度与结果。

## ⚠️ 已知限制

- 扫描进行期间，面板数据按较低频率刷新；扫描结束后恢复即时更新。
- 一个仓库的分片只在**同一次派单**内成立：之后再追加派遣的同仓库搬运工会重新分片，认领机制保证不会重复搬运，但可能出现重复扫描。
- 未安装 Carpet 时搬运工不可见，仅能通过指令与面板观察作业结果。
- 专用服务端在没有客户端连入时，指令输出中的物品名为英文。
- 搬运工的「显示名」只影响面板与网页；头顶名牌、聊天与死亡消息仍是注册名。
- 附魔名称按客户端语言文件显示，模组新增的附魔若缺少语言键会退回英文注册名。
- 面板布局面向 720P 及以上分辨率设计，极窄窗口下部分区域会按可用空间降级或隐藏；自绘列表有「文字块不越下一行」的自检，越界会在日志里打出 `行块自检` 警告。
