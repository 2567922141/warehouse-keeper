# Warehouse Keeper v1.1.2

Issue #3 修复版 + 一个新功能。这一版针对 2026/10/5 的实机反馈（GitHub issue #3「10.5问题总结」）修掉取货取错物品、工作方块界面标签栏压住物品栏、显示名不同步与头顶名牌不更新四项，并在**取货页**加上按物品分类筛选的下拉。

## 🐛 问题修复

- **取货取到名字相似的物品（打「石头」结果取成「平滑石头」）**：物品名解析原来是「id 精确 + 子串包含」，而中文永远不是合法 id，于是只能走子串分支、再按**库存最多**挑一个 —— 仓库里没有石头时，剩下的唯一候选就成了「平滑石头」。现在改成三段：**id 精确 → 名字精确（唯一才认）→ 子串包含（唯一才认）**；命中多种一律拒绝，并按库存从多到少列出候选（最多 10 条，附可直接复制使用的 id）。另外补了一条兜底：输入本身是合法物品 id 但仓库里没有（例如 `stone`，而索引里只有 `smooth_stone`）时直接回「仓库中没有这件物品」，绝不拿名字沾边的顶包。面板取货与 `/warehouse order` 同源，行为一致；`/warehouse find` 的既有行为不变。
- **工作方块界面里标签栏压住物品栏（工作台 / 熔炉打开配方书时）**：这类界面（`AbstractRecipeBookScreen`：工作台、熔炉、高炉、烟熏炉等）打开配方书时原版会把界面右移，而本模组拿不到真实几何（26.2 没有公开的访问口），只能按「界面居中」估算外框，算出的竖栏正好落在被右移的物品栏上。现在这类界面**不再显示容器标签栏**（它们本来也不在整理范围内、标签也主要给箱子打）；开箱子、木桶、铁砧等界面照旧显示，位置与点击都不受影响。
- **改完显示名，面板先报成功 / 别人看不到**：面板显示名输入框上限 32 与服务端 24 不一致，写长了会被服务端拒绝，而按钮已经先写了成功文案。现在上限对齐 24，并在本地先拦掉换行、制表符、控制字符与颜色代码 `§`；按钮提示改为「已发送：…」，成功与否以状态栏里服务端回执为准（面板→服务端→其他客户端的同步通路本身一直是通的）。
- **改完显示名，假人头顶名牌仍是原始编号**：原版玩家名牌 = 记分板队伍装饰 + 档案名，`setCustomName` 对玩家完全无效（服务端一直改不动）。这一版新增一处**纯客户端**的渲染替换：装了本模组的客户端里，假人头顶名牌会显示面板里设的显示名。服务端零改动、不写存档、不生成任何实体、不发新数据包。

## ✨ 新功能（取货页按分类筛选）

- **取货页筛选行现在是「筛选框 | 分类：… ▾ | 仓库：… ▾」三件套**，分类下拉与仓库下拉是同一套实现（展开、滚动、点选、滚动条一致）。
- 分类候选按当前取货范围里**实际存在**的物品现算（不依赖服务端按需查询通道，老服务端也能用），顺序照创造栏页签顺序，不会出现空分类；超过 8 条自动出现滑块与「a~b / n」计数。
- 清单、标题里的「共 N 种物品」、点一行填入取货框、滚轮上限都跟着分类一起筛；表头会显示「（分类：xxx）」。
- 切换仓库时按分类**键**保住选中项（候选顺序/数量变了也跟着移），那一类在新范围里不存在才回到「全部分类」，不会让下标悄悄指到另一个分类。
- 三个控件的宽度按行宽计算，窗口再窄也会依次收缩（分类按钮 → 仓库按钮 → 筛选框），不会互相压住。

## 🔧 顺手修掉的隐患

- **取货页清单受「物品」页搜索词影响**：取货页的清单原来复用了「物品」页的取数口，会被那一页搜索框里的字过滤掉一部分。现在取货页直接读快照，只受**取货页自己**的筛选框 + 仓库 + 分类控制。

## ⬆️ 升级提示

- **旧版本替换即可**：删除 `mods/` 里的旧 `warehouse-keeper-*.jar`，换成 `warehouse-keeper-1.1.2.jar`。注意不要在 `mods/` 里同时留下新旧两个 jar（同一模组 ID 会导致加载失败）。
- 配置、标签、权限、仓库定义、审计与索引都在 `config/warehouse-keeper/` 下，原样沿用；本版**没有**改索引格式，不需要重新扫描仓库。
- 联机时**服务端与客户端都要装**本模组，且**版本需一致**；显示名的「头顶名牌替换」只在**装了 1.1.2 客户端**的玩家自己那一侧生效。
- 升级后建议依次点一遍：取货页三个控件是否在一行且不重叠、打开分类下拉选一类再回到「全部分类」、面板给假人设显示名后另一台装了模组的客户端能否看到新名字、开熔炉/工作台时右侧是否已无标签栏。

## ⚠️ 已知限制

- **未装模组的原版客户端**仍看到假人的 Carpet 注册名（新名字只通过本模组在客户端渲染时替换，服务端并没有改名）；玩家列表（Tab）、指令、任务、`/warehouse bot list` 也一律使用注册名 —— 注册名是身份，改了等于换人。
- 分类候选只看「取货范围」、不看筛选框里的字：因此可能出现「某分类 + 某关键字 = 0 种物品」（表头会显示 0，可切换分类或清空筛选）。
- 「仓库 → 物品」子页的分类下拉候选来自服务端查询结果；服务端不支持按需查询（较旧版本服务端）时它只剩「全部分类」。
- `/warehouse order` 现在遇到多种匹配会拒绝并列出候选，不再替玩家猜（属于本次的刻意修复，见上）。
- 工作方块（工作台/熔炉/高炉/烟熏炉等）界面不再显示容器标签栏（按 issue #3 的方案）；铁砧、切石机等不受配方书影响的界面不受此限制。
- 扫描进行期间，面板数据按较低频率刷新；扫描结束后恢复即时更新。
- 未安装 Carpet 时搬运工不可见，仅能通过指令与面板观察作业结果。
- 专用服务端在没有客户端连入时，指令输出中的物品名为英文。
- 附魔名称按客户端语言文件显示，模组新增的附魔若缺少语言键会退回英文注册名。
- 面板布局面向 720P 及以上分辨率设计，极窄窗口下部分区域会按可用空间降级或隐藏。
